The app offers seamless user experiences, including authentication, ride booking, real-time tracking, and offline functionality.

## Overview

In today's fast-paced urban environments, efficient and reliable transportation solutions are essential. Our **Careem Clone App** aims to revolutionize the way users book and manage rides by offering a seamless and user-centric experience. Leveraging modern technologies like **Jetpack Compose**, **Kotlin**, and **Firebase**, the application ensures scalability, security, and high performance.

## Features

- **Splash Screen:** Displays the app logo with a green background upon launch.
- **Main Activity:** Welcoming screen that allows users to continue with Google or phone number.
- **Phone Verification:** Users can input their phone number for verification.
- **User Profile:** Manage user profiles and settings.
- **Ride Booking:** Book rides with pickup and drop-off locations.
- **Real-Time Tracking:** Track rides in real-time with driver locations.
- **Payment Integration:** Multiple payment methods including credit/debit cards and digital wallets.
- **Offline Functionality:** Access essential features without an active internet connection.
- **Push Notifications:** Receive notifications for ride confirmations, driver arrivals, and promotions.

## Screens

### Frontend Screens

1. **Splash Screen**
   - Displays the app logo in the center of a green background.

2. **Main Activity Screen**
   - Displays a greeting message along with two buttons:
     - Continue with Google
     - Continue with Phone Number
   - Includes a message "Good to see you again!" above the buttons.

3. **Phone Verification Screen**
   - Contains a back arrow and a help icon in the top corners.
   - Displays a title and prompt asking for the user's phone number.
   - Provides an input field for the phone number and a continue button.

4. **User Profile Screen**
   - View and edit user details.
   - Manage payment methods and preferences.

5. **Ride Booking Screen**
   - Input pickup and drop-off locations.
   - Choose ride options (e.g., economy, premium).

6. **Ride Tracking Screen**
   - Real-time map view showing the driver's location and ride status.
